# Task checklists and formats

Working formats for Tasks 1, 3, 6 and 8. The structure of the JAP itself is governed by `joint-action-plan-template.md`.

## 1. Extraction map (Task 1)

For each sector report, extract the following. The right-hand column gives the location in an OLePFM Sector Reform Design Report produced with the `olepfm-session-manager` skill; for a report on a different or older template, find the equivalent content.

| Extract | Where to find it in the report |
|---|---|
| Development outcomes and public sector results targeted | Section 2.1; Annex Table 1.1 |
| Key public sector challenges | Section 2.2; Annex Table 1.1 |
| Priority PFM bottlenecks: name, impact and feasibility ratings, contribution to the challenges | Section 3.2.2; Annex Table 2.3 (constituent bottlenecks and their Technical / Institutional / PFM type in Annex Table 2.2) |
| For each priority bottleneck: underlying causes, stakeholders and the change objective it maps to | Annex Table 3.1 (header row carries the change objective; the working five-whys annex carries the coded raw causes) |
| Change objectives and reform results, with the reforms required for each | Section 4.1; Annex Table 3.1 |
| The action plan: reform results with their key steps, timing and responsible organizations | Annex Table 3.5 |
| Stakeholders: authorizers, team leaders, results team, coalition members; commitment and power to block | Section 4.2; Annex Tables 3.2 and 3.3 |
| Systems, capacity and TA: digital systems, capacity development, TA packages and the reform results each enables | Section 4.3; Annex Table 3.4 |
| Feasibility ratings and the count of High, Medium and Low results | Section 4.1 summary table; Chapter 5 |

Produce a structured internal summary of each sector's content before proceeding to Task 2. Do not present it to the user unless requested; use it to guide the synthesis and drafting.

## 2. Bottleneck synthesis table (Task 3)

Present the cross-cutting clusters in this form and invite the user to confirm the clustering before drafting:

| Cross-cutting bottleneck | Sector 1 manifestation | Sector 2 manifestation | Sector 3 manifestation | Common underlying causes |
|---|---|---|---|---|
| [Cluster name in plain language] | [Figures and description, with citation] | [Figures and description, with citation] | [Figures and description, with citation] | [Causes that cut across the sectors] |

List separately the sector-specific bottlenecks that appear in only one report; these inform sector-specific reform results or actions rather than cross-sectoral objectives.

## 3. Gap-analysis formats (Task 6)

**(a) Gaps: bottlenecks or problems in the reports that the JAP does not address.** List each as: source sector | section of the report where it appears | the JAP objective it would fall under.

**(b) Missing actions: reforms proposed in the reports that the JAP does not capture.**

| Action | Source report | Report change objective | Recommended JAP reform result |
|---|---|---|---|

**(c) Additions: content in the JAP not grounded in the reports.** Identify what came from supplementary sources or from the framework itself. Flag each item either as an appropriate system-level cross-sectoral enabler (retain and note as such) or as going beyond the evidence base (for the user to decide).

Present the gap analysis as a structured section with a recommendation on which gaps to address before finalising, and wait for the user's decisions before Task 7.

## 4. Finalisation checklist (Task 8)

| Check | Detail |
|---|---|
| Baselines | All marked TBD, with a note that they will be established through a joint assessment at the start of implementation |
| Placeholders | All clearly marked, with instructions for completion |
| Abbreviations | Table complete for every acronym used in the document |
| Action numbering | Cross-sectoral: sequential (1.1.1, 1.1.2); sector-specific: sector suffix (1.1.H, 1.1.E) |
| Timeframes | Year 1, Year 1–2 and so on; no calendar years |
| Lead agencies | Named consistently, using the agreed abbreviations throughout |
| Cover | Title, version number and date correct |
| Terminology | Objective for top-level groupings; Reform Result for the changes within each; Action for table entries; no residual Pillar, Sub-Pillar or MPA |
| Bottleneck groups | The group headings in Section 1.3 are the objective titles of Section 2.2, in the same order and number |
| Systems, capacity and TA | Section 3.2 content explicitly linked to named reform results in Section 2.2 |
| Word document | Follows the Word template as set out under Output in `joint-action-plan.md` (this skill's SKILL.md): headings, footer, tables, Box 1, table of contents; skeleton-residue scan at 0 |
| Annexes | None; the document ends at the bibliography |
| Bibliography | Every source cited in the document is listed |
