## Quick Reference: Formatting and Writing Conventions

**[This section documents the key conventions used in this JAP format. Include in the template but delete from the final document before sharing externally.]**

**Terminology:**
- Use **Objective** for the top-level grouping (do not use 'Pillar' in the final document — 'Pillar' may be used informally in discussions but the document uses 'Objective')
- Use **Reform Result** for the specific change sought within each Objective (do not use 'Sub-Pillar' or 'Objective' at this level)
- Use **Action** for the specific steps in the cross-sectoral and sector-specific reform tables

**Action numbering:**
- Cross-sectoral actions: numbered sequentially within each Reform Result (e.g. 1.1.1, 1.1.2, 1.1.3)
- Sector-specific actions: numbered with a sector suffix (e.g. 1.1.H for Health, 1.1.E for Education, 1.1.A for Agriculture) — use the first letter of the sector name or an agreed abbreviation

**Tables:**
- Cross-sectoral and sector-specific reforms use 3-column tables (# | Action | Responsible) with timeframe as a fourth column where included
- The results framework uses a 5-column table (Reform Result | Indicator | Baseline | Target | Data Source)
- Table 1 (sector reform results by objective) and Table 2 (theory of change) appear in Section C only

**Citations:**
- Use bracketed citations for all figures drawn from specific sources: [MoH 2024], [PEFA 2026], [sector diagnostic report name, year]
- Do not use footnotes — all citations inline

**Length guidance:**
- Full document (excluding cover, ToC, abbreviations): approximately 25–35 pages for a three-sector JAP
- Section A (Introduction): 2–3 pages
- Section B (Problem Statement): 2–3 pages
- Section C (Theory of Change): 1–2 pages including tables
- Section D (Reform Objectives and Actions): 10–15 pages
- Section E (Implementation Arrangements): 3–4 pages
- Section F (Results Framework): 1–2 pages
