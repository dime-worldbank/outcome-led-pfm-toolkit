# Reform frameworks for the Joint Action Plan

Read this at Task 4. The structural architecture of the JAP, its objectives and reform results, is guided by one or both of two PFM reform frameworks, selected according to the sectors and development outcomes in scope. Both use the same hierarchy: **Objective** (the strategic goal, the top-level grouping) → **Reform Result** (the specific change sought within each objective).

## Framework 1 — PFM for Service Delivery

Use when the JAP addresses sectors focused on frontline service delivery outcomes: health, education, water, agriculture, social protection.

| Objective | Reform Results |
|---|---|
| **1 — Financing Service Delivery** | 1.1 Needs-based resource allocation |
| | 1.2 Reliable financing flows |
| | 1.3 Financial management at facility and local level |
| **2 — Putting Resources to Work** | 2.1 Human resources |
| | 2.2 Operational inputs |
| | 2.3 Infrastructure and equipment |
| **3 — Participation, Management and Accountability for Results** | 3.1 Performance management |
| | 3.2 Citizen engagement |
| | 3.3 Integrated information |

## Framework 2 — PFM for Jobs and Resilience

Use when the JAP addresses sectors focused on fiscal sustainability, economic growth, revenue mobilisation or public investment outcomes.

| Objective | Reform Results |
|---|---|
| **1 — Domestic Revenue Mobilisation** | 1.1 Revenue policy and medium-term revenue strategy |
| | 1.2 Tax administration modernisation |
| | 1.3 Compliance risk management and taxpayer engagement |
| **2 — Fiscal Sustainability and Resilience** | 2.1 Medium-term fiscal framework and budgeting |
| | 2.2 Expenditure rationalisation |
| | 2.3 Treasury and cash management |
| | 2.4 Fiscal risk management |
| **3 — Public Investment, Infrastructure and Procurement** | 3.1 Public investment management, PPPs and project management |
| | 3.2 Asset management and maintenance |
| | 3.3 Procurement and private sector development |
| | 3.4 SOE governance and utility management |
| **4 — Transparency, Accountability and Enabling Environment** | 4.1 Fiscal transparency |
| | 4.2 Audit and oversight |
| | 4.3 Accounting and data systems |

## Selecting the framework

| Scope of the JAP | Framework to use |
|---|---|
| All sectors are service delivery (health, education, water, agriculture, social protection) | Framework 1 only |
| All sectors are economic or fiscal (revenue, fiscal management, public investment) | Framework 2 only |
| The JAP spans both service delivery and economic or fiscal outcomes | A combination: draw the relevant objectives and reform results from each and consolidate overlapping elements |

When combining frameworks, check for overlap (both include elements of fiscal management and accountability, for example) and consolidate to avoid duplication.

Present the proposed objective and reform result structure to the user for approval before drafting. If it is not immediately clear which framework applies, present both with a brief explanation of the differences and ask the user to confirm.
