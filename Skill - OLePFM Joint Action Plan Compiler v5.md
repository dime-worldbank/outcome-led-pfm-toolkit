# Skill: OLePFM Joint Action Plan Compiler
### Version 5 — September 2026

---

## What This Skill Does

This skill guides the compilation of a Joint Action Plan (JAP) from multiple OLePFM (Outcome-Led PFM Reform) sector diagnostic reports. It follows an eight-step process, producing a document that:

- Synthesises the bottlenecks and reform actions from multiple sector diagnostics into a single, jointly-owned reform agenda
- Follows the structure and formatting conventions set out in the **OLePFM Joint Action Plan Annotated Skeleton Template**
- Uses one or both of two PFM reform frameworks to organise its objectives and reform results, depending on the sectors and outcomes in scope
- Is grounded in evidence and language from the sector diagnostics so that stakeholders who participated in those processes recognise their work in the joint document

**Trigger phrases:** "compile a joint action plan from these diagnostic reports" / "synthesise these OLePFM reports into a joint strategy" / "draft a joint reform agenda from these sector diagnoses" / "prepare a multi-sector action plan using the OLePFM approach"

---

## Reference Documents

This skill is designed to be used with two reference documents uploaded alongside the sector diagnostic reports:

1. **OLePFM Joint Action Plan — Annotated Skeleton Template** — the master guide for document structure, section content, formatting conventions, and writing guidance. Every section of the JAP output follows this template. Ask the user to upload it at the start of each task.

2. **OLePFM Synthesis Handbook (Making Public Resources Count for Development)** — the methodological backbone providing the outcome-led framing, theory of change concepts, and reform design principles applied throughout.

If neither is available, ask the user to upload them before proceeding. If the skeleton template is unavailable, use the Malawi Joint Action Plan for Local Authority Service Delivery (post-workshop draft, September 2026) as the format reference.

## The Eight Steps

### Step 1: Gather and Extract from Source Documents

**Confirm with the user before starting:**
- Which sector diagnostic reports are available — ask the user to upload any not yet in the conversation
- Whether the Annotated Skeleton Template is available — ask the user to upload it if not
- The country or region context and the name of the national PFM strategy or reform process the JAP should feed into
- Whether supplementary sources should be searched (WBG intranet and web) or whether the skill should work from uploaded documents only

Do not begin extraction or drafting until all source documents are confirmed and uploaded.

**For each uploaded OLePFM sector diagnostic report, use document_chat to extract:**

| Extract | Where to find it |
|---|---|
| Development outcomes and public sector results targeted | Section 1–2 of diagnostic |
| Key public sector challenges | Section 2.2 or equivalent |
| Priority PFM bottlenecks — name, underlying causes, impact rating, feasibility rating, stakeholders, and the change objective each maps to | Section 3–4 or bottleneck analysis section |
| Change objectives and reform results — for each, the full list of reform results and proposed reforms | Section 4 or change objectives section |
| Action plan matrix — all columns: sub-bottleneck / causes / stakeholders / reform result / reforms required | Annex |
| Systems, capacity and TA — digital systems priorities, capacity development priorities, TA packages, and their links to specific reform results | Systems/capacity/TA section or equivalent |

Produce a structured internal summary of each sector's content before proceeding to Step 2. Do not present this summary to the user unless requested — use it internally to guide the synthesis and drafting steps.

### Step 2: Search for Supplementary Context

*(Only if authorised by the user in Step 1)*

Run parallel searches on the WBG intranet and web for:

- Recent PFM assessments for the country (PEFA, public expenditure reviews, fiduciary risk assessments)
- Intergovernmental fiscal transfer and local government financing data
- Local authority performance assessments (e.g. LAPA or equivalent)
- National development strategy and PFM strategy documents
- Relevant World Bank project documentation (local governance, service delivery, fiscal management operations)

Summarise key findings for the user, identifying which sources will be drawn on in the JAP and for which sections. These sources are primarily used to ground Sections A and B — the introduction, reform context, and problem statement.

---

### Step 3: Synthesise Common Bottlenecks

Read across all sector extractions from Step 1 to identify bottlenecks appearing in two or more sector reports.

For each cross-cutting bottleneck cluster:
- Name the cluster in clear, non-technical language that stakeholders will recognise
- List which sectors it appears in, with the sector-specific manifestation and precise figures from each report
- Note the common underlying causes that cut across sectors
- Note any sector-specific bottlenecks that do not appear cross-sectorally — these will inform sector-specific reform results or actions rather than cross-sectoral objectives

**Present the bottleneck synthesis to the user as a table** before proceeding, and invite confirmation that the clustering is correct and complete. This is the foundation of Section B of the JAP — it must be agreed before drafting begins.

Example table format:

| Cross-cutting bottleneck | Sector 1 manifestation | Sector 2 manifestation | Sector 3 manifestation | Common underlying causes |
|---|---|---|---|---|
| [Bottleneck name] | [Figures and description] | [Figures and description] | [Figures and description] | [Causes] |

### Step 4: Select the Reform Framework and Design the Objective and Reform Result Structure

The structural architecture of the JAP — its objectives and reform results — is guided by one or both of two PFM reform frameworks, selected based on the sectors and development outcomes in scope. Both frameworks use the same terminology hierarchy: **Objective** (the strategic goal, the top-level grouping) → **Reform Result** (the specific change sought within each objective).

**Selecting the framework:**

| Scope of JAP | Framework to use |
|---|---|
| All sectors are service delivery (health, education, water, agriculture, social protection) | Framework 1 only |
| All sectors are economic/fiscal (revenue, fiscal management, public investment) | Framework 2 only |
| JAP spans both service delivery and economic/fiscal outcomes | Combination — draw relevant objectives and reform results from each; consolidate overlapping elements |

When combining frameworks, check for overlap (e.g. both include elements of fiscal management and accountability) and consolidate to avoid duplication.

**Present the proposed objective and reform result structure to the user for approval before proceeding to drafting.** If it is not immediately clear which framework applies, present both to the user with a brief explanation and ask them to confirm.

### Step 5: Draft the Joint Action Plan

Use the **Annotated Skeleton Template** as the master guide for every section — structure, content, length, and formatting. Read the annotation for each section before drafting it. The document sections and their key content requirements are summarised below.

**Document structure:**

| Section | Title | Key content |
|---|---|---|
| — | Cover page | Title; country; sectors; draft version; date; ministry logos |
| — | Table of Contents | All sections A–F with page numbers |
| — | Abbreviations | Two-column table; all acronyms used in document |
| **A** | Introduction and Reform Context | Purpose; country ambition; the problem including Box 1 |
| **B** | Problem Statement | Common pattern; binding constraints in two groups |
| **C** | Theory of Change | Two to three paragraphs; Table 1 (sector results by objective); Table 2 (five-column results chain) |
| **D** | Reform Objectives and Actions | By Objective → Reform Result; standard format for each Reform Result |
| **E** | Implementation Arrangements | Five subsections — see below |
| **F** | Reform Results Framework | Five-column table; cross-sectoral indicators; all baselines TBD |
| — | Bibliography | All cited sources |

| Subsection | Content |
|---|---|

| **II. ### Step 6: Cross-Check Completeness Against the Source Diagnoses

Before presenting the draft to the user, systematically compare the JAP against each sector diagnostic to identify:

**(a) Gaps — bottlenecks or problems from the diagnostics not addressed in the JAP:**
List each gap with: source sector | relevant section of the diagnostic | which JAP objective it would fall under.

**(b) Missing actions — proposed reforms in the diagnostics not captured in the JAP:**
Present as a table: action | source diagnostic | relevant diagnostic change objective | recommended JAP reform result.

**(c) Additions — content in the JAP not grounded in the sector diagnostics:**
Identify what has been added from supplementary sources or the framework template. Flag whether these are appropriate system-level cross-sectoral enablers (to be retained and noted as such) or go beyond the evidence base (to be flagged for user decision).

Present the gap analysis to the user as a structured document section and recommend which gaps to address before finalising. Await user decisions before proceeding to Step 7.

---

### Step 7: Revise and Iterate

Incorporate user decisions from the gap analysis and any other feedback.

- Use **edit_document** for targeted changes — individual sections, paragraphs, action rows, or indicator rows. This is the default approach.
- Use **create_document** only if the user requests a structural reorganisation that affects more than half the document.
- Track which version is current and confirm the version number with the user after each revision cycle.

## Edge Cases

| Situation | How to handle |
|---|---|
| Fewer than three sector diagnostics | Proceed but flag that synthesis is less robust; note JAP will need updating as additional diagnoses are completed |
| Sector diagnostics using different OLePFM templates | Adapt extraction to the format used; map all content to the same synthesis framework in Step 3 |
| Skeleton template not uploaded | Ask the user to upload it. If unavailable, use the Malawi JAP post-workshop draft (September 2026) as the format reference |
| User wants to include sectors without completed diagnoses | Note as 'diagnosis in preparation' in Section A introduction and Box 1; flag that inclusion requires a subsequent update |
| Five or more sector diagnostics | Limit objectives to three or four and reform results to eight to twelve; group closely related bottlenecks rather than creating a separate reform result for each |
| Ambiguous framework selection | Present both frameworks to the user with a brief explanation of the differences and ask them to confirm before proceeding |
| Sector diagnostic has no systems/capacity/TA section | Infer key systems and capacity requirements from the reform actions proposed under each change objective; use these to populate Section E.II |
